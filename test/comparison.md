## 三、结论

- **检索质量**：基础题两代都命中目标菜谱；**列表/一般/多跳/复杂题的差距最大**——传统 RAG 系统性受‘鸡蛋花’泛化文本块污染，且对抽象概念/属性约束(减肥/低糖/少油/菜系)无能为力；GraphRAG 通过图实体检索(鸡胸肉/郫县豆瓣酱)与图路径(豆腐--Ingredient)命中更相关的内容。
- **耗时**：GraphRAG 平均 ~4.3× 更慢（多出多次 LLM 分析 + 图遍历），但换来检索相关性的大幅提升；传统 RAG 快在 list 类(3s)。
- **路由(优化后)**：简单问题 → hybrid_traditional；中等问题 → combined（图+混合结合，实测纯图RAG对主题型查询召回弱，故改为结合）；困难问题 → combined。
- **已知短板**：GraphRAG 的子图提取在实体映射失败时返回空‘知识子图’(0概念)；多跳对‘替代猪肉’这类查询仍围绕原实体；这些是后续可优化的方向。
